## ✨ Visual Highlights & Interactive Features

- **Interactive Quantum Shift:** Toggle between light states (`⚡ Activate Flux` / `🌑 Deactivate`) to alter environmental background modes and swap hologram entity assets (`lionoff.jpg` ↔ `lion.jpg`).
- **Animated Cosmic Auroras:** Background mesh gradients (`conic-gradient`, `radial-gradient`) driven by spinning and pulsing keyframe animations.
- **Dynamic Particle Field:** Programmatically generated star particle system covering full viewport dimensions.
- **Glassmorphism UI Container:** Reactive glass card featuring backdrop blur filters, glowing borders, and 3D perspective tilts.
- **Laser-Swept Buttons:** Custom CSS button hover state featuring high-speed diagonal light-sweep effects (`skewX`).
- **HyperReveal Image Animations:** Smooth CSS transition keyframes handling opacity, scaling, brightness, and contrast adjustments upon image state shifts.

---

## 🛠️ Built With

- **HTML5:** Clean structural markup and semantic interactive elements.
- **CSS3:** Custom CSS variables, 3D transform perspectives, backdrop filters, keyframe animations, and mesh gradients.
- **JavaScript (Vanilla ES6+):** DOM manipulation, dynamic particle generation, event handling, and state toggling.
